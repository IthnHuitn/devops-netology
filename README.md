📁 Локальные директории и файлы Terraform
.terraform/ — директория с плагинами и кэшем Terraform (создается при terraform init)

.terraform.tfstate.lock.info — файлы блокировки состояния (предотвращают одновременное изменение состояния)

📄 Файлы состояния (state files)
*.tfstate — файлы текущего состояния инфраструктуры

*.tfstate.* — любые производные файлы состояния (например, резервные копии .tfstate.backup)

🔒 Файлы с переменными и секретами
*.tfvars, *.tfvars.json — файлы с значениями переменных, которые часто содержат чувствительные данные (пароли, ключи доступа)

.terraformrc, terraform.rc — конфигурационные файлы CLI Terraform (могут содержать настройки доступа)

🛠 Файлы переопределений (overrides)
override.tf, override.tf.json — файлы для локального переопределения конфигураций

*_override.tf, *_override.tf.json — любые файлы с суффиксом _override

📊 Логи и временные файлы
crash.log, crash.*.log — логи аварийного завершения Terraform
